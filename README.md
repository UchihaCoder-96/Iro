# Iro

A code-only game engine built from scratch with **C++ and Vulkan**.

Iro is primarily a learning project focused on understanding low-level graphics programming, Vulkan, and real-time engine architecture.

## Goals

* Learn Vulkan and GPU programming
* Build a simple 2D engine first
* Gradually extend it to 3D
* Keep the engine reusable for future games and graphics projects

## Tech Stack

* C++
* Vulkan
* GLFW
* GLM
* CMake

> Work in progress.
